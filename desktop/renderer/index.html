Hospital ADS

Aplicación de escritorio

Inicio de sesión

Ingresa con tu usuario del hospital. Dependiendo de tu rol (médico, enfermería o administración) verás diferentes opciones.

Esta es solo la pantalla inicial. Después conectaremos este login con el backend para validar médicos, enfermería y administradores.

Ingresa tu usuario y contraseña para continuar.

Módulo Médico

Menú

Bienvenido(a) al módulo médico

Aquí podrás consultar pacientes, registrar notas de evolución, generar órdenes de laboratorio y revisar resultados.

En el siguiente paso conectaremos cada opción con el backend y la base de datos.

Módulo de Enfermería

Desde este módulo podrás registrar notas de enfermería, apoyar en el seguimiento de indicaciones médicas y consultar información básica de los pacientes asignados.

Más adelante agregaremos las pantallas específicas (registro de signos vitales, evolución de enfermería, etc.).

Módulo de Administración

Aquí se administran usuarios del sistema (médicos, enfermería, recepción) y catálogos básicos del hospital.

En pasos posteriores implementaremos la creación de usuarios y la asignación de roles usando la base de datos que ya tienes.
